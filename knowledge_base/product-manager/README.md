# 产品经理知识库

这是一套面向产品经理，尤其是 AI 产品经理的工作知识库。它用于帮助 Agent 解释概念、拆解问题、生成模板和审阅方案；不用于替代用户研究、真实业务数据、法律意见或实时市场事实。

## 导入 Coze

将本目录下的 Markdown 文件逐个上传到同一个知识库。保留标题和二级标题，便于按主题检索。智能体提示词中加入：

```text
优先从知识库检索产品方法、模板和术语定义。
知识库只提供通用方法，不可将其当作用户、市场、岗位或公司事实。
若回答需要真实数据、用户反馈、JD 原文或外部政策，要求用户提供材料或调用对应资料来源。
回答时先说明适用场景，再给出最小可执行下一步；不要把框架术语堆成清单。
```

如希望只上传一个文件，可直接使用上级目录的 `product-manager-knowledge-base.md`，它已合并以下全部章节。

## 使用原则

1. 先确认用户、场景、目标和限制，再选方法。
2. 将事实、假设、意见和待验证项分开。
3. 一个需求必须说明用户价值、成功标准和不做什么。
4. AI 输出需要来源、限制和失败路径；不能因语言流畅就视为正确。
5. 先做最小验证，再扩大范围。
