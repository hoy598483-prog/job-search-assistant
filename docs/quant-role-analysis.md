## 若选择量化研究作为第二项目

推荐的是一个小而完整的研究项目，而不是直接训练复杂模型：

**项目：A 股或公开市场数据的可复现因子研究原型。**

1. 定义一个可检验假设，例如某个公开可得的价格/成交量特征是否与未来收益相关。
2. 数据清洗、特征构造、训练/验证时间切分与简单基准比较。
3. 输出统计结果、限制、风险与图表，保存可复现代码和研究报告。
4. 只在有明确依据时讨论回测；不把历史结果表述为交易建议或未来收益保证。

这个项目可同时训练 Python、pandas/NumPy、假设检验、时间序列、Git、研究表达和结果导向。它不能在一周内证明成熟的量化策略能力，也不应伪装为真实投资业绩。
