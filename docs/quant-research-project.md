# 可复现量化研究原型：项目定义

## 用户问题

研究人员面对市场直觉时，容易直接从图形或回测结果得出结论。原型把一个直觉转为可复现的研究流程：数据检查 → 特征定义 → 时间切分 → 基准比较 → 结果与限制。

## 首个研究问题

用公开或用户合法提供的日频价格与成交量数据，检验一个简单、明确的横截面或时间序列特征是否与未来收益存在稳定关系。具体特征必须在获得数据后确定，并记录定义；不预设有效。

## 数据契约

首版 CSV 至少包含：`date`、`asset`、`close`。如使用成交量特征，再加入 `volume`。数据源、复权方式、币种、交易日历、缺失值策略和样本区间必须记录在配置中。

## 最小实验

1. 对每个资产按日期排序，检查重复、缺失与异常价格。
2. 只使用时点以前的数据构造特征，并定义预测窗口。
3. 按时间而非随机拆分训练期与验证期。
4. 与一个朴素基准比较，如零预测、持有基准或简单历史均值。
5. 输出指标、图表、假设是否被当前样本支持，以及数据/方法限制。

## 当前实现

`quant_research.py` 已实现最小数据检查、过去收益率特征、未来收益标签与按日期的训练/验证切分。训练集标签必须在切分日期前结束，避免使用验证期价格作为训练标签。`test_quant_research.py` 使用合成价格序列验证这一约束；该序列只用于程序测试，不是市场研究结果。

## 验收

- 从同一份 CSV 和配置可重跑相同结果。
- 没有用未来价格生成当期特征。
- 报告能定位每个数据处理和统计结论的来源。
- 报告明确不是投资建议，也不将历史结果视为未来表现保证。
