# 每日课程与选区小问答

## 开始课程

1. 工作台接受Codex生成的一周计划后，每天都有“打开当天课程 / 基础讲解与提问”入口。
2. 课程页面单独连接Codex，读取当天任务、岗位目标及本人已确认的全局背景摘要，不发送原始简历。
3. 用户确认后生成2–4个知识点：基础讲解、例子、理解检查问题，加上先修检查、项目练习、验收依据和参考资料。
4. “允许联网”需单独勾选并确认。只有课程生成模式可使用网络搜索；主聊天与局部问答不因此获得联网权限。资源应来自实际检索，链接显示为模型推荐而非人工核验。
5. 课程先保存为草案，用户采用后记录版本，不会改动当天任务完成状态。可重新生成并保留旧课程版本。

## 原文旁边提问

在课程、工作台或笔记本中选中文字，右键或点击“询问这个知识点”，打开页面右侧的小问答区。浏览器主页面不跳转。
普通HTTP(S)网页中，选中文字后右键选择“用Codex解释这段内容”，打开Chrome原生Side Panel。首次更新可能需要接受新增的右键菜单/侧边栏权限；至少Chrome116。
小问答单独连接官方Codex CLI，点击发送时确认：选区最多6000字、附近段落最多3000字、课程目标、最近问答，以及可选的已确认背景摘要。不会带入主聊天、整份简历或整份课程。
本机口令只通过Chrome注册的Native Messaging管道返回，旧的HTTP GET /handshake不再公开返回口令。
快捷按钮可填入“按我的基础解释”“举例”“先问我”“考我一道题”。点击“返回原文位置”恢复原文选区；在页面已导航、刷新或内容已改变后可能无法恢复，需要重新选择。
课程检查问题可先填写自己的答案，再点击“请助教检查我的回答”，问题在同一个小问答区内展开；回答反馈不自动标记掌握或任务完成。

## 上下文和数据

每个知识点使用独立本地会话键：方向、课程版本/文档、选区及周边内容的SHA256。相同选区可恢复历史，不同知识点不会混入主聊天。
问答保存在chrome.storage.local的selectionQA:*，每次重发最近最多20条消息；不是官方CLI原生thread/resume，也未实现无限历史或自动知识掌握诊断。
已选原文只由用户动作捕获；未添加全站持续读取。Chrome内部页面及受保护页面不可使用外部右键采集，跨域框架可能只得到选中文字。
本人的理解或疑问需要自己编辑并确认后才收藏到学习笔记本。收藏不代表已掌握；不会自动把整个问答转入主对话或全局个人背景。
课程版本保存在learningCourses:<方向ID>，临时选区请求在chrome.storage.session，个人资料和正文不写入服务审计日志。
页面刷新后定位Range失效；问答记录仍在，重新选择同一原文可恢复内容。
